# Design direction: a calm client desk

A working surface for a solo consultant, with the precision of a well-designed address book. Top navigation instead of the earlier red sidebar. Wide typographic headers, aligned client rows, a compact next-meeting rail and evidence treated as readable correspondence.

Typography: self-hosted Manrope for display and DM Sans for interface text. Weight 450/500/600/700, tabular dates, 14px minimum regular labels and 16px reading text. No stock portraits or invented analytics. Client monograms identify fictional companies; official Fireflies and Calendly assets identify sources.

Palette: deep navy #10213B anchors the app header and Claude chat; blue #1B4290 is the primary action color with a softer #88ACFF navigation highlight. Ink #10233F, cool-white background #F5F7FB, white working surfaces, borders #DCE4EF and muted text #536580. Positive states retain a restrained teal; errors retain semantic red. The user requested a sleek dark-blue direction with the precision associated with financial products, while keeping ClientDesk’s own typography, monogram and layouts. This supersedes the initial red app palette; the O’Reilly course decks retain their established branding.

Geometry: top navigation, 80rem content maximum, 8px spacing base, rows separated by hairlines. Cards only for an actual contained object such as a meeting. 10px panel radius, 6px fields/buttons. No blanket gradients, ambient glows or ornamental metric cards.

Interaction: text-preserving error states; two-step task review in a dialog with focus containment; keyboard escape, visible focus, reduced-motion support. Responsive layout collapses to one column without hiding the primary action. Source evidence and proposed owner/date remain distinct.

References: existing course feedback and official provider assets. The local redesign-existing-projects skill was consulted for hierarchy, state coverage and removal of generic patterns. Its optional marketing effects were not applied to this working CRM. No external design skill was installed.
