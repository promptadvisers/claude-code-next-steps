# Design assets

Typeface packages: @fontsource-variable/manrope and @fontsource-variable/dm-sans (5.3.0), self-hosted with their supplied SIL Open Font Licenses. Selected Latin variable files and licenses are retained in fonts/. The application imports the locked packages directly.

Brand assets: official Fireflies, Calendly, Vercel, Supabase and GitHub SVGs retained from the course authoring folder. Copied originals in brands/; provenance is included in [brands/PROVENANCE.md](brands/PROVENANCE.md) and [brands/sources.json](brands/sources.json). Fictional client monograms are CSS typesetting, not real company marks.

Visual direction: DESIGN.md. Live tokens: tokens.css. Exact production styling: ../03-build/clientdesk/app/globals.css. Browser screenshots: ../04-verification/screenshots. No external skill was installed and no generated stock imagery was added.
